# CINTAC ComexControl - Frontend

Interfaz de usuario desarrollada con React y Vite. 
Implementa Control de Acceso Basado en Roles (RBAC) y un sistema de cálculo de cotizaciones marítimas basado en archivos tarifarios Excel.

## Ejecución local
1. `npm install`
2. Configurar `.env.local` con `VITE_API_URL=http://localhost:10000`
3. `npm run dev`
